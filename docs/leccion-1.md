# Lección 1 — ¿Qué es el desarrollo web? (5 min)

> Guion de narración para el video. Video **no listado** en YouTube. Demostración **solo** en editor en línea (CodePen). Sin branding ni referencia a los autores en pantalla ni en el código.
>
> ⚠️ Lección conceptual. No se construye el proyecto todavía. El alumno EXPLORA y OBSERVA, no practica.

## 🎯 Objetivo
Al terminar, el estudiante podrá explicar qué es el desarrollo web, reconocer que HTML y CSS son sus dos pilares, y entender que toda página web está hecha de ese código.

## 🎬 Guion

### Segmento 1 — El gancho (0:00 – 0:45)
- **[En pantalla]**: La página de perfil **terminada** (resultado final del curso) con foto, nombre, lista de hobbies y enlaces, ya con estilo.
- **[Narración]**: "Hola. ¿Ves esta página? Tiene foto, colores, enlaces. Al terminar este curso de una hora, tú vas a haber construido una igual, con tu propia información, y la vas a poder compartir con quien quieras. Y lo mejor, sin instalar absolutamente nada. Solo tu navegador. Empecemos."

### Segmento 2 — ¿Qué es el desarrollo web? (0:45 – 2:00)
- **[En pantalla]**: Texto grande "Usar la web no es lo mismo que construir la web". Iconos de navegar contra construir.
- **[Narración]**: "Todos los días usas la web. Ves videos, lees, chateas. Hoy vas a hacer algo distinto, vas a construirla. Desarrollar para la web es crear las páginas que el navegador te muestra. ¿Y qué es un sitio web? Es un conjunto de páginas que tu navegador, sea Chrome, Firefox o el que uses, lee y dibuja en la pantalla."

### Segmento 3 — Los dos pilares: HTML y CSS (2:00 – 3:15)
- **[En pantalla]**: Analogía de la casa. A la izquierda paredes y estructura igual a HTML. A la derecha pintura y decoración igual a CSS.
- **[Narración]**: "Toda página web se construye con dos lenguajes. El primero es HTML, y es la estructura. Los títulos, los párrafos, las imágenes. Piensa en HTML como los huesos y las paredes de una casa, define qué hay y dónde. El segundo es CSS, y es el estilo. Los colores, los tamaños, la tipografía. Si HTML son las paredes, CSS es la pintura y la decoración."

### Segmento 4 — El momento revelación: inspecciona una web real (3:15 – 4:15)
- **[En pantalla]**: Una página web conocida. Clic derecho, "Inspeccionar", y se abre el panel con el HTML resaltándose al pasar el cursor.
- **[Narración]**: "Te voy a mostrar algo que pocos saben. Entra a CUALQUIER página de internet, haz clic derecho y elige 'Inspeccionar'. ¿Ves todo ese código? Eso es HTML y CSS. Absolutamente todas las páginas que usas están hechas con lo mismo que vas a aprender aquí. No hay magia, hay código. Y al final de esta hora, tú lo vas a saber leer y escribir."

### Segmento 5 — Explora y observa (4:15 – 5:00)
- **[En pantalla]**: CodePen de demostración con un `<h1>`, un `<p>` y una regla CSS de color.
- **[Narración]**: "Abre el enlace de la descripción. No vas a construir nada todavía, solo quiero que EXPLORES. A la izquierda está el HTML, abajo el CSS y a la derecha el resultado. Cambia una palabra del título y cambia un color en el CSS. Observa cómo el navegador se actualiza al instante. Es para que veas con tus propios ojos cómo se relacionan. En la lección 2 empezamos a construir tu perfil de verdad."
